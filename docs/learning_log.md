## 学習記録 03：命名規則の検証

## 目的
Mayaで選択したオブジェクトの名前が、Unreal Engine向けの命名規則に合っているか検証する。

## 学習した内容
-Pythonの re モジュール
-正規表現による文字列の検証
-re.match() によるパターン照合
-validate_name() による検証処理の関数化
-True / False を使った判定結果の返却
-obj.split("|")[-1] によるオブジェクト名の取得

## 命名規則
-SM_から始まる
-接頭辞の後ろは英字または数字のみ
-接頭辞だけで終わる名前は不可

## テスト結果
-SM_Rock：OK
-SM_StoneWall：OK
-Rock：NG
-SM_Rock-01：NG
-SM_：NG

## 今回の学び
-命名規則の判定を関数に分離することで、他の処理からも再利用できるようになる

# 学習記録 04：Transformの検証

## 目的
Mayaで選択したオブジェクトのTransformを取得し、基準値から外れている属性を検出する

## 学習した内容
-cmds.getAttr() による属性値の取得
-Translate・Rotate・Scaleの基本的な違い
-Freeze Transformationsによる値の変化
-TOLERANCE による許容誤差の設定
-abs() による差の絶対値の計算
-any() による複数の値の条件判定
-problems.append() による問題属性の記録
-関数による検証処理の分離

# 今回の検証ルール
-Translateの基準値：(0, 0, 0)
-Rotateの基準値：(0, 0, 0)
-Scaleの基準値：(1, 1, 1)
-許容誤差：0.001

# テスト結果
-基準値どおりのTransform：Transform OK
-Translate Xを3に変更：Translateを検出
-Rotate Yを30に変更：Rotateを検出
-Scale Yを2に変更：Scaleを検出

## 今回の学び
-PythonでMayaの属性値を取得し、基準値と比較することで、確認が必要な属性を検出できる。
