# 学習記録 01：Mayaのオブジェクト取得

## 目的
Mayaで選択したオブジェクトをPythonで取得する。

## 学習した内容
- maya.cmdsの読み込み
- cmds.ls()による選択オブジェクトの取得
- リスト型（list）のデータ
- if / elseによる条件分岐
- 関数（def）とreturnによる処理の分離
- type()によるデータ型の確認
- len()によるデータ数の取得

## テスト結果
- オブジェクトを1つ選択：成功
- 複数オブジェクトを選択：成功
- オブジェクトを選択しない：成功
- 取得したデータ型の確認：成功
- 取得したオブジェクト数の確認：成功

## 今回の学び
cmds.ls(selection=True, long=True)で選択中のオブジェクトを取得できる。
取得結果はリストとして扱える。
関数は定義するだけでなく、呼び出して戻り値を受け取る必要がある。
